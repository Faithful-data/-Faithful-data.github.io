# Faith Atogun — Professional Portfolio

## Folder structure

- `index.html` — page structure and editable contact/profile links
- `css/style.css` — visual design, responsive layout and themes
- `js/data.js` — **main content file to edit** (skills, experience, projects and services)
- `js/main.js` — functionality only; normally do not edit
- `assets/images/profile.png` — profile photo

## Quick editing guide

### 1. Update projects
Open `js/data.js` and edit the `projects` array. Each project has:
- `title`
- `number`
- `tags`
- `description`
- `link`

Replace `#contact` with your live GitHub, Power BI or project URL when ready.

### 2. Update experience
Edit the `experience` array in `js/data.js`.

### 3. Update skills and services
Edit the `skills` and `services` arrays in `js/data.js`.

### 4. Update contact links
Edit the email, LinkedIn and portfolio links in `index.html`.

### 5. Change colours
Edit `--brand` and `--brand-2` at the top of `css/style.css`.

### 6. Replace your photo
Replace `assets/images/profile.png` with another image using the same filename.
